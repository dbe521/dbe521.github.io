# 费用报销系统 · 演示版使用说明（销售用）

## 一、怎么打开

双击 `费用报销系统-Demo.html`，用 Chrome / Edge 打开即可。

- 不需要安装任何软件，不需要联网，不需要服务器
- 演示数据全部内置，点坏了刷新页面即可还原
- 如需彻底还原，点右上角「重置演示数据」

## 一之二、登录（第一步）

打开后是登录页，左侧深墨蓝品牌面板、右侧选角色：

- **boss 老板**（周明远·总经理）—— 看全公司支出，审批大额单据终审
- **cw 财务**（王芳·财务主管）—— 财务复核、出纳付款、配置审批流

**密码已经填好（123）**，点一下角色卡再点「进入系统」即可，不用手输。
演示中想换角色：点右上角「**退出登录**」回到登录页，重新选角色进入（密码已填好 123，直接点「进入系统」）。左下角不再放角色切换按钮，避免误点跳出角色视角。

## 二、两个角色（登录后按角色显示对应页面）

| 角色 | 身份 | 首屏 | 左侧可见菜单 | 演示重点 |
|---|---|---|---|---|
| **boss 老板** | 周明远（总经理） | **经营驾驶舱** | 经营驾驶舱 / 待我审批 / 全部单据（含采购请款单、费用报销单两个子项）/ 审批流配置 / 通知与日志 | 看全公司支出；审批大额单据（终审）；**出纳工作台与报表统计不显示** |
| **cw 财务** | 王芳（财务主管） | **财务工作台** | 财务工作台 / 待我审批 / 全部单据（含两个子项）/ **出纳工作台** / **报表统计** / 审批流配置 / 通知与日志 | 财务复核；出纳工作台登记付款、上传回单；报表统计导出 CSV；配置审批流 |

两个角色的菜单、首屏卡片、图表与引导文案都不同——**这就是系统按角色分发待办的核心价值**。出纳付款按钮只有财务角色可点，老板视角显示"仅查看"。
换角色：点右上角「**退出登录**」回到登录页，重新选角色进入（密码已填好，直接点进入）。

## 二之二、二级菜单怎么用（重点）

「全部单据」下面的 **采购请款单 / 费用报销单** 是**管理者视角的单据列表**：

- 点「采购请款单」→ 列出所有用户提交的采购请款单（11 张），标题显示"全部单据 · 采购请款"
- 点「费用报销单」→ 列出所有用户的费用报销单
- **点任意一行 → 打开该单的整页明细**（审批流、单据信息、明细、附件、付款情况）
- 老板和财务看到的都是全量单据，不是自己的
- 需要演示"员工怎么提单"时，点列表右上角 **「＋ 采购请款单」/「＋ 费用报销单」** 进入空白填单页，提交后自动按金额算出审批链

## 三、九屏演示顺序（建议讲 10 分钟）

1. **工作台** — 一打开就看到：待我审批几单、已付款多少钱、采购 vs 报销各多少、部门支出分布
2. **待我审批** — 点任意一行，整页展示审批详情：审批流节点、单据信息、明细、附件，右侧吸顶"通过 / 驳回"
3. **全部单据** — 按采购请款 / 费用报销筛选，看状态与历史
4. **出纳工作台** — 待支付 / 已付款两栏；点「登记付款」选结算方式（月结/现款/周结）与付款账户，模拟上传回单
5. **报表统计** — 按类型、结算方式、状态汇总，可导出 CSV
6. **审批流配置** — 按"单据类型 + 结算方式 + 金额区间"决定谁来审，可现场改数字演示
7. **通知与日志** — 审批留痕、谁在什么时间做了什么
8. **采购请款单** — 员工怎么提单：部门二选一、供应商、结算方式三选一、明细行、附件
9. **费用报销单** — 报销场景：用途、金额、领款人与收款账号、附件

## 四、可以现场点给客户看的操作

- 审批：在待我审批里点开单据 → 通过 / 驳回（驳回会记录原因，单据变红）
- 付款：出纳工作台 → 登记付款 → 状态变"已付款"，回单留痕
- 提单：填单页 → 提交审批 → 自动按金额算出审批链（如现款 ≥5000 自动加老板终审）
- 配置：审批流配置改阈值 → 保存 → 下次提单按新规则走
- 导出：报表统计 → 导出 CSV

所有操作只影响当前页面，刷新即还原，可放心演示。

## 五、常用话术

- **"老板一打开就知道钱花在哪"** → 工作台 + 报表统计
- **"大额单据必须老板终审，小额财务直审，规则可配"** → 审批流配置 + 待我审批切换角色
- **"从申请到付款全链路留痕，随时可追溯"** → 通知与日志 + 审批详情里的审批流节点
- **"我们的人录单很简单"** → 采购请款单 / 费用报销单填表页

## 六、常见问题

| 问题 | 处理 |
|---|---|
| 打开是空白 / 排版错乱 | 换 Chrome 或 Edge 打开（不要用 IE） |
| 提示"无法访问本地文件" | 把整个 Demo 文件夹复制到本地磁盘再打开，不要从微信/压缩包里直接运行 |
| 想恢复初始状态 | 刷新页面，或点右上角「重置演示数据」 |
| 导出的 CSV 在哪 | 浏览器默认下载目录，文件名 `费用报销统计.csv` |
| 想改成自己公司的数据 | 联系技术同学（数据写在 HTML 文件里的 DEMO 常量中） |
