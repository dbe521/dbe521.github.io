AI 业务场景介绍站 · 使用说明（第二版）
=====================================================================

一、怎么打开
---------------------------------------------------------------------
1. 整个 ai-scenario-site-v2 文件夹是一个完整整体，移动或拷贝时必须整体复制，
   不要只复制 index.html，否则样式、字体、图标与界面图会全部丢失。
2. 双击 index.html 即可打开，默认用系统浏览器。
3. 不需要联网，不需要装软件，不需要启动服务。
4. 客户电脑上打开时，若浏览器提示"是否允许运行脚本"，选择允许。

推荐浏览器：Chrome、Edge、Safari 的较新版本。不建议使用 IE。

二、文件结构
---------------------------------------------------------------------
index.html                     首页，单页长滚动，两个版面
ai-finance.html                AI 财务

assets/css/layout.css          版式与组件（改版式时改这里）
assets/js/content.js           【你唯一需要改的文件】全站文案与场景数据
assets/js/app.js               渲染与交互逻辑，一般不用动
assets/icons/sprite.js         本地图标（运行时用）
assets/fonts/geist-*.woff2     自托管西文字体
assets/img/*.webp              14 张系统界面示意图（7 场景 × 概览 + 明细）

  ├─ screen.css                界面图专用样式
  ├─ 01-ai-finance-overview.html 等 14 个界面稿源文件
  ├─ gen_lib.py / gen_screens.py  生成界面稿
  ├─ render.py                 渲染成图片（含渲染前结构自检）
  ├─ diag.py                   布局诊断
  └─ contact_sheet.py          生成总览图

三、改文案（最常用）
---------------------------------------------------------------------
1. 用文本编辑器打开 assets/js/content.js（推荐 VS Code，不要用 Word）
2. 只改引号里的中文，保留引号、逗号、括号
3. 保存后刷新页面即可生效，8 个页面同步更新
4. 某段暂时没有内容：把引号留空写成 ""，页面显示"待补充"
5. 正式文案全部替换后，把顶部 DEMO_MODE: true 改成 false，
   页脚的示例提示会消失

四、页面结构（每个场景详情页）
---------------------------------------------------------------------
① 首屏：左侧场景名与一句话价值 + 右侧系统界面图（点击可放大）
② 打开首页能看到什么：这段说明文字配在界面图下方
③ 现在的做法卡在哪里：4 条业务痛点
④ 我们怎么解决：全宽色带，含技术要点
⑤ 带来什么改变：4 条方向性改变
⑥ 决策人三问：合作前最常被追问的三个问题
⑦ 实施案例（仅 AI 财务场景有）：价值主张、上线规模、月结投入对比、能力里程碑
⑧ 界面明细：全幅大图，放在「核心功能」之前
⑨ 核心功能 / 落地路径 / 适用对象
⑩ 页尾：回到所属版面 + 上一个/下一个场景

五、三套配色皮肤
---------------------------------------------------------------------
右上角三个图标按钮随时切换，选择会被浏览器记住：
  月亮    深色科技    默认，现场演示用
  太阳    彩色浅色    发给客户自己看、或需要打印时使用
  对比度  苹果极简    近白底、大留白，正式汇报或投屏时使用

想改某个场景的专属色：在 content.js 里改该场景的 accent
  accent: { d: "#22D3EE", l: "#0E7490" }
  d 是深色皮肤下的颜色，l 是浅色与极简皮肤下的颜色
建议浅色取值比深色更深一些，保证对比度。

六、界面图怎么换
---------------------------------------------------------------------
站点是按【文件名】引用图片的，所以换图不需要改任何代码：
1. 把你的新图导出为 WebP 或 PNG
2. 用同名文件覆盖 assets/img/ 下的对应文件，例如：
     assets/img/ai-finance-overview.webp   首屏那张
     assets/img/ai-finance-detail.webp     「界面明细」那张
3. 命名规则：{场景id}-overview.webp 与 {场景id}-detail.webp
   场景 id 见 content.js 里 scenarios 下的键名
4. 建议尺寸 2800×1750（16:10），最低不低于 1400×875

想改界面图上的文字/数据，请改 _screens/ 里的界面稿源文件，
或在 content.js 的 screen 字段里改标题与说明，然后重新生成图片。

七、图片灯箱
---------------------------------------------------------------------
首屏图框与「界面明细」大图都可点击放大：
点击图片 → 全屏查看原图；点击空白处或按 Esc 关闭。
现场演示时可用它把界面放大给客户看细节。

八、新增一个业务场景
---------------------------------------------------------------------
1. 复制任意详情页文件，重命名为英文小写的新名字，例如 smart-warehouse.html
2. 打开新文件，把 body 标签上的 data-scenario 改成新的 id
3. 在 content.js 里：
   a. 在 scenarios 中复制一整块场景数据，改 id 与内容
      （qa、screen、case 字段可按需保留或删除）
   b. 在 order 数组里加上新的 id（决定上一个/下一个的顺序）
   c. 在 sections 里把新 id 加进对应版面的 scenarios 数组
4. 准备两张界面图放进 assets/img/，命名 {新id}-overview.webp / -detail.webp
5. 保存刷新，首页卡片与新页面会自动出现

九、打印或导出 PDF
---------------------------------------------------------------------
浏览器按 Command+P（Windows 为 Ctrl+P）。
页面已做打印适配：导航、按钮、动效、灯箱会自动隐藏，卡片不会被截断。
建议打印前先切到"彩色浅色"或"苹果极简"皮肤。

十、常见问题
---------------------------------------------------------------------
Q: 打开是空白页？
A: 三个可能。一是只复制了 index.html 没带上 assets 文件夹；
   二是浏览器拦截了脚本，需要在设置里允许；
   三是刚改过 content.js 且有语法错误，撤销改动即可。

Q: 图片不显示，出现破图图标？
A: 检查 assets/img/ 下的文件名是否与 content.js 里 screen 字段写的一致。

Q: 字体和设计稿不一样？
A: 西文数字用打包在 assets/fonts 里的 Geist 字体，中文自动使用系统字体
   （macOS 苹方、Windows 微软雅黑）。这是有意设计，保证离线可用。

Q: 换到别的电脑打开，主题变了？
A: 配色选择保存在浏览器本地，换电脑会回到默认深色皮肤，点右上角即可切换。

Q: 可以放到共享盘或网站服务器上吗？
A: 可以。全部使用相对路径，放到共享盘任何子目录、或上传到静态网站托管
   都能正常工作。

十一、数字口径
---------------------------------------------------------------------
- 界面示意图内的数值：演示样例，每张图底部已统一标注
  "系统界面示意 · 数据为演示样例"
- 实施案例区块：来自客户上线材料的口径，区块内已标注
  "以上为上线演示口径的示例数据，非真实业绩承诺"
- 其余正文文案：不写百分比与金额
