# 自动抄表&状态监控 · 客户演示版（vol2）使用说明

> 单文件演示包 · 2026-10-23 · 数据为仿真演示数据 · 直接双击即可演示，无需安装任何环境

## 如何打开

**双击文件夹中的 `自动抄表状态监控-演示版.html` 即可开始演示。**

- 推荐使用 Chrome 或 Edge 浏览器
- **无需联网、无需安装任何软件**——所有样式、数据、功能都内置在这一个文件里
- 可整体拷贝此文件夹通过微信 / QQ / 邮件发给他人，对方双击即用（只发这一个 html 文件也可以）

## 演示流程（约 10 分钟）

1. **封面**：登录账号已预填（admin / demo1234），直接点「登录」
2. **运维大屏**：全局 KPI、重点设备、印量趋势（图表自动轮播，可手动切换）、告警流、采集日志；**点击顶部 KPI 卡片（设备总数/在线/离线/告警/低量耗材）可展开对应设备清单**（默认折叠，可再点卡片或「折叠」收起）
3. **概览**：KPI、最近告警、印量 Top、月度趋势、定时轮询、低量耗材
4. **设备**：搜索 / 品牌 / 状态筛选、分页、批量操作演示
5. **设备详情**：推荐 C360I（碳粉严重不足）、iR-ADV C5560（碳粉偏低）、MP 3555（离线错误态）三台数据最完整
6. **发现**：点「开始扫描」演示网段扫描动效，逐台发现新设备并可「加入设备」
7. **告警**：级别/状态/类型筛选、确认告警；规则页展示六类告警规则
8. **报表**：切换「计数器 / 标准计数」，展示增量统计与四张可视化图表
9. **自动通知设置**：收件人管理、SMTP 配置、运维日报频率（每周/每月/每季度）、「发送测试邮件」

顶部彩色菜单可随时切换到任意页面；大屏页也有同样菜单。所有页面右上角均有「退出登录」按钮（确认后返回登录页）。

## 注意事项

- 本演示包**不连接真实打印机与网络**，所有扫描 / 采集 / 发送均为界面模拟，可放心点击任意按钮
- 演示数据：24 台设备、18 条告警事件、7 个轮询模块、近 12 个月印量趋势；刷新页面后数据复位
- 本版本（vol2）不含「状态」独立页，设备健康信息已在「概览」「设备」「告警」等页体现
