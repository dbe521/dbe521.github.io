上线必要性 / 为什么需要算力智能调度中枢

没有统一入口，AI 用量就无法治理

企业用 AI，缺的不是模型，是一道可管控的入口

成本要能归集数据要能管控调用要能追溯

知识工作者已在广泛使用 AI，流入大模型的企业数据中也包含相当比例的敏感信息①。只要入口不统一，成本归集、敏感数据管控与调用审计就都无从落地——这不是管理能力问题，而是缺少一层基础设施。算力智能调度中枢把这三件事收进同一个可配置、可计量、可追溯的通道，让「怎么管着用」成为可执行、可验收的规则。

成本失控

守不住

安全黑洞

个人账号处理内部信息，敏感内容外泄无审计，事后追责缺少凭据①。

留不下

资产无沉淀

优秀提示词与场景散落在个人手里，人一走经验就断，AI 能力无法在组织里复利。

这四件事靠制度约束管不住，只能靠统一入口——这正是算力智能调度中枢必须承担的角色。

WHY NOW / 为什么是现在

这不是超前布局，而是行业共识

统一网关（AI Gateway）已成为大模型企业接入的基础设施标配；我们做的是它的中国企业级、信创级落地。

AI 已经在用，治理不能再等

员工侧的使用早已发生：敏感数据外流、账号重复采购、调用无留痕，是每天都在累积的现实成本。监管口径与内部审计要求已经明确，越晚统一入口，历史调用越难追溯、账单越难归集。

问题不是要不要上，而是每多等一天，无法追溯的调用就多一天。

政策有东风

国务院国资委部署央企「AI+」专项行动②；《生成式人工智能服务管理暂行办法》划定合规底线——要用 AI，更要可控地用。

准入看数据流向

涉敏内容能否强制走内网私有模型、能否出具全链路审计留痕，是事业单位及关注信息安全的领导们眼下必须处理、且无法绕开的待处理事项。

验收看审计与账单

调用留痕、按部门出账、配额与预算口径，是内审与财务部门能签字验收的交付物；这层能力必须在入口处建设，事后补不了。

ROUTING / 智能调度

省钱与合规，可以兼得

路由策略是平台的技术灵魂——每个请求，都自动找到「最合适」的那一个模型。

能力路由

代码、长文、多模态各归其位——任务自动匹配更擅长的模型，效果与效率同时兼顾。

成本路由

简单任务自动降级至更经济的模型，综合成本预计下降 15%–30%（模拟测算口径，实际以客户真实用量评估为准）。

合规路由

涉敏内容强制走内网私有模型，数据不出域；非敏任务才允许调用外部渠道，策略可配置、可审计。

可用性路由

上游限流、故障或价格变动时自动切换备用渠道，业务侧无感。

CONSOLE / 控制台

两种交付形态，两套适配界面

MaaS 平台版侧重自助用量、费率与模型选择的透明度；私有化部署版侧重渠道状态、凭据与调用排障。两者共用同一组模型、计费与审计能力，界面按部署场景分别组织。

模型广场 · 按交付场景组织信息

平台版以模型目录呈现厂商、单价与延迟；私有化部署版按厂商分组呈现可用模型与渠道归属。

两套交付版本共用同一组模型、费率与审计数据；渠道异常在有降级或离线时主动提示，并在所有相关位置标红，异常解除后自动收起。

USER VALUE / 使用者价值

统一入口之后，日常使用会有什么不同

前面讲的是治理约束与交付形态，这一节回到每天真正用这套系统的人——四件事不再需要自己处理，平台在后台承担，使用侧只管把活干完。

01

一个入口，多模型按需切换

不必分别注册与维护多个账号；按任务选模型，存量工具按兼容协议直连，原系统不用改。

02

统一额度与配额

用量有预算、有归属，无需个人垫付；月底自动出账、费用按部门分摊，不必再自己报销对账。

03

链路自动择优，调用更稳

上游限流或故障时自动回退备用渠道，业务侧无感；不必自己判断该换哪个账号、重试几次。

04

场景模板开箱即用

写作、翻译、代码、汇报等常用场景直接可用；哪些内容能发、发到哪里，由平台统一把关。

让 AI 用得起来，更管得住

用得起，是每一笔调用都有预算、有归属；管得住，是敏感部门与涉敏内容强制走内网私有模型、数据不出域。两件事在同一个入口里完成，不靠制度反复叮嘱。

智能调度 · 管得住

敏感部门与涉敏信息，可单独配置强制内网私有模型

按部门、按数据级别设定路由策略：敏感部门的涉敏内容一律走内网私有模型，数据不出域；其余任务仍按能力与成本择优调度，不因管控牺牲好用。策略由平台统一执行、调用全量留痕，信息安全责任不再落在每个使用者自己的判断上。
